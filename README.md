# 动作库 · Action Library

一套自用的 3D 动作素材库方案：**搜集 → 入库 → 分类打标 → 缩略图 → 网页预览 → 套到自己的角色上**。

```text
skill/action-library/   可复用的技能说明（给 AI 助手看的工作手册）
docs/                   两份方案：怎么找素材、怎么建库
web/                    本地预览站（Python 标准库 + three.js）
```

## 这套东西解决什么问题

网上动作素材散、格式乱、许可还各不相同。直接往里扒，最后一定变成：

- 下回来一堆不能商用的东西，某天要做商业项目得整体重审
- 文件名乱码、路径中文，引擎里加载失败
- 几千条动作没有预览、没有分类，找一条要翻半小时

这套流程把上面三件事分别解决：**许可分层 + 英文命名 + 多维标签和缩略图**。

## 目录分层

```text
00_说明与索引/   规则、总表、授权记录、library.db
01_原始下载/     原封不动的压缩包（永不改名、永不删除）
02_动作数据/     解开、转过格式的原始动作
03_整理后/       统一骨架、按用途分类的成品
04_临时/         解压、试验、待删（只有这里可以随便删）
05_导出给引擎/   Godot / Unity 直接吃的成品
90_网页系统/     预览站
```

一条动作只能往上走，不能跳级。

## 许可红线

| 授权 | 能进商业包 | 要署名 | 能进的层 |
|---|---|---|---|
| CC0 / 公有领域 | 能 | 不用 | 02 / 03 / 05 |
| CC-BY | 能 | 必须 | 02 / 03 / 05 |
| 仅限非商用 | 不能 | —— | 只有 01 / 02 |
| 授权不明 | 不能 | —— | 只有 01 / 02 |

库里只要混进一条来路不明的素材，整个商业包都要重审。所以宁可少收。

## 预览站长什么样

一个 Python 文件起服务，一个端口同时给页面、API、文件：

```bash
cd web
python3 server.py            # http://127.0.0.1:8099
./start.sh                   # 后台常驻
```

- `/` 动作库：卡片列表、搜索、标签筛选、收藏、播放预览
- `/rig.html` 套动作工作室：上传自己的角色（`.fbx/.glb/.gltf`，带贴图就压 zip）→ 选库里的动作 → 套上 → 看预览 → 下载带动画的 GLB

服务端依赖：Python 3（标准库即可）、Blender（渲染缩略图与套动作时需要）。
前端依赖已放在 `web/vendor/`（three.js，MIT），通过 importmap 引入，不需要 npm。

## 快速开始

```bash
# 1. 起服务
cd web && python3 server.py

# 2. 打开
open http://127.0.0.1:8099

# 3. 导入第一批动作（把文件放进库目录后重建索引）
curl -X POST http://127.0.0.1:8099/api/reindex
```

路径默认写死在 `server.py` 顶部（`/home/<user>/动作库`），换机器改那几行即可。

## 技能怎么用

`skill/action-library/SKILL.md` 是给 AI 助手看的工作手册，包含：

- 判断一个源值不值得下的标准
- 四条已验证的下载通道（DuckDuckGo HTML 端点、GitHub API、itch.io 免登录流程、官方样例库直链）
- 非人形 / 怪兽 / 虫类的关键词表
- 入库六步、命名规范、状态口径
- 多维标签体系（含生物「形态」维度）
- 缩略图渲染参数与取景公式
- 重定向算法与五个必踩的坑
- 验收清单

把它放进助手的技能目录即可被自动检索到。

## 已知边界

- **不抓需要登录或付费的站**（Sketchfab、TurboSquid、CGTrader 等），这类跳过并记录原因
- **静态模型不收**，只收有动画的
- Google Drive 文件夹直链经常拿不到内容，别在这上面死磕
- 重定向只处理骨骼动画；morph target（形变）动画不能跨骨架套用
